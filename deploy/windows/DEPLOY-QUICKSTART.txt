族谱处理台 · 正式环境更新（预编译包）
================================================

本包已包含编译好的 server\dist 与 admin-web\dist，服务器上【不需要】npm install、也不需要编译。
执行脚本只做：停服务 → 备份 → 备份数据库 → 同步表结构 → 覆盖编译产物 → 启动 → 自检，失败自动回滚。

一、准备
  1. 远程桌面连 139.224.15.127（administrator）
  2. 把 zupu-update-20261105-0939.zip 从本机拖进远程桌面（例如放到 C:\node\rupuutils\）

二、覆盖
  3. 解压 zip，把里面的 server、admin-web、sql、deploy、prebuilt 等目录
     覆盖到 C:\node\rupuutils\zupu\
     （资源管理器提示重名时选“替换目标中的文件”）
     注意：server\.env 与 server\.env.production 不在包里，线上配置不会被改。

三、一键执行
  4. 双击 C:\node\rupuutils\zupu\deploy\windows\deploy-prebuilt.cmd
  5. UAC 提示点“是”，等窗口跑完
     看到绿色 DEPLOY DONE 即成功（约 30~60 秒）

四、自检与回滚
  - 脚本会打印 http GET / -> 200、auth probe -> 401（401 表示数据库连接正常）
  - 备份在 zupu\backup\<时间戳>\（含 server-dist、admin-web-dist、db-zupu_scan-<时间戳>.sql）
  - 失败时会自动还原上一版 dist 并重启服务
  - 日志：zupu\logs\deploy-<时间戳>.log

五、本次数据库变更（脚本已自动执行，幂等）
  - users 表新增 role / enabled / deleted_at 三个字段
  - 新建 ai_usage_records 表（大模型生图用量记录）
  - 说明：服务启动时也会自动补齐，所以即使跳过 SQL 步骤也不会缺表

六、更新后
  浏览器打开 http://139.224.15.127:8090 ，按 Ctrl+F5 强制刷新，避免旧前端缓存。
